## 📺 pureTV

### 你的每一个创作，都值得被公平对待。


你的电视，也应该由你做主：**自定义电视桌面，自由安装、卸载应用**，让大屏按自己的喜好呈现，把想用的留下，把不需要的整理掉。

pureTV 希望成为一个属于创作者与用户的电视应用分享平台。你可以免费、自由地上架自己的电视应用，把亲手做出的工具、游戏和桌面分享给他人，也可以发现、体验其他人的成果。


> **没有算法约束，没有用户画像，只有自由。**

| 创作，值得分享                             | 桌面，随你定义                             | 应用，自由选择                                         |
| :----------------------------------------- | :----------------------------------------- | :----------------------------------------------------- |
| 免费上架电视应用，自主发现、体验彼此的作品 | 更换启动器，自定义支持的电视桌面布局与背景 | 自由安装、卸载应用，让电视装下自己真正想用的工具与游戏 |

#### 从分享作品，到在电视上用起来

配套的电脑端管理器支持 **Windows · macOS · Linux**，通过 ADB 连接 Android TV / Google TV。你可以导入并安装 APK，批量管理、卸载应用，切换启动器，并用可视化画布调整受支持桌面的布局与背景。核心系统组件与当前默认启动器受保护，方便自由整理，也避免误操作。

也可通过 **MCP** 让 Agent 操作已打开的管理器，让发现、安装与使用衔接起来。
